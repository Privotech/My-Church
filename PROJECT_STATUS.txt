================================================================================
                      ANIMATED BACKGROUND DETAILS
================================================================================

Component File: components/AnimatedBackground.tsx
Canvas ID: aria-hidden="true" (accessibility)
CSS Class: .animated-background

Animation Features:
  • 100 particles spawned continuously
  • 5 vibrant colors: #ff6b6b, #f7e74c, #6bcf6b, #6b9cf7, #a76bf7
  • Each particle:
    - Starts at random position
    - Moves with random velocity (±1.5 pixels/frame)
    - Decays from size 1-6 to 0.2
    - Fades opacity as it shrinks
    - Respawns when fully faded
  
  • Window resize handled automatically
  • High DPI display support (2x pixel ratio max)
  • Cleanup on component unmount prevents memory leaks

CSS Animation Overlay:
  • 15-second gradient animation loop
  • Subtle opacity (0.2) to avoid overwhelming content
  • Synchronized with particle animation for depth
